# Агропромцифра: вторая версия прототипа

Отдельная версия сайта с редакцией текстов от 30 сентября 2026 года.

- [Открыть новую версию](https://nbnandreu-svg.github.io/apc-site-prototype-v2/)
- [Открыть предыдущую версию](https://nbnandreu-svg.github.io/apc-site-prototype/)

Уточнены аудитории, задачи заказчиков, инженерные компетенции и семь направлений продуктов и услуг. Сохранены иллюстрации, интерактивные вкладки и анимации.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Открыть `http://127.0.0.1:5177/apc-site-prototype-v2/`.

## Сборка и публикация

```sh
npm run pages:build
npm run preview
```

Статическая сборка находится в `dist-pages`. Изменения в ветке `codex/site-v2` запускают GitHub Actions, который обновляет ветку `gh-pages`. В настройках GitHub Pages выбран источник `gh-pages`, каталог `/`.

Предыдущая версия находится в отдельном репозитории, поэтому публикация этой версии ее не обновляет.

## Статус прототипа

Форма демонстрационная и не отправляет заявки. Кнопка скачивания чек-листа отключена до подключения материала. В метаданных сохранен запрет индексации `noindex, nofollow`.

Числа внутри иллюстрации первого экрана обозначены как условные данные. В карточках проектов описаны задачи и решения без неподтвержденных количественных эффектов.
